# 本子猎手 v3.3

把一整条「复制文件名 → 找作品 → 按优先级挑最好的汉化版本 → 下载」的活儿做成一个桌面软件。
三个站一起搜，按重点排序，只下第一个，下完自动打包成 zip。

---

## 它做什么

1. 你把**完整标题或文件名**粘进去（一行一个，支持批量），比如
   `ママさんバレーでママオナホ・開幕戦と決勝戦(ai翻译)`
2. 软件在三个站同时找：
   - **紳士漫畫**（wnacg）—— 地址从发布页 `https://wnacg01.link/` 实时解析
   - **禁漫天堂**（JM）—— 地址从发布页 `https://jmcomictt.site/` 实时解析
   - **nhentai** —— 固定域名，走代理
3. 按优先级排序后**自动下载第一个**：
   ```
   汉化组 / 字幕组  >  汉化  >  个人汉化 / 机翻  >  日文原版
   ```
   同一档里再按「匹配度」和「来源」排（绅士漫畫能直接下 zip，优先）。
4. 全名匹配不到时，自动退到**关键字匹配**：拆掉方括号、去掉「第几步 / 中文汉化 / DL版 / 无修正」这类垃圾后缀，取其中最长的日文片段去撞，撞到就下。
5. 保存目录可以随时浏览选择，支持记住上次目录。

## 界面

- **液态玻璃**：整个窗口是一层玻璃。底下直接读你当前的桌面壁纸文件（按窗口所在显示器 cover 裁切，窗口移动/启动时重抓），玻璃负责模糊；读不到壁纸才回退到截屏。
- **壁纸取色**：从壁纸里抽主色，派生强调色，深浅两套主题各自一套色。
- **明暗主题**：右上角月亮 / 太阳图标切换，记住选择。
- 结果列表直接显示：来源、类型（彩色点）、标题、页数、匹配度、大小；双击任意一行就下那一行。

## 界面入口

- **保存到**：搜索框下面一行，**首页直接可改**——点进去输入或 `Ctrl+V` 粘贴路径，回车生效（带引号的 `"E:\本子"` 会自动剥引号，不存在的目录自动创建，非法路径直接拒并在状态栏提示）；右边「浏览…」走系统选择框
- **设置**：右上角齿轮，里面有代理地址、重新解析站点地址、版本号（保存目录已移到首页，这里不再重复放）
- **白天/夜间**：齿轮左边的月亮/太阳


1. 双击 `本子猎手.exe`（同目录那 3 个 dll 不要删）
2. 粘贴标题 → 点「搜索并下载」
3. 想换目标：列表里点一行 → 「下载选中」
4. `Ctrl+Enter` 也能触发搜索

## 日志

出问题先看这里，别猜：

```
%LOCALAPPDATA%\BenziHunter\logs\app-YYYYMMDD.log     ← 按天分文件，保留 7 天
```

每行长这样，`+秒数` 是**启动后经过的秒数**，看周期性问题的间隔全靠它：

```
2026-11-02 17:09:24.418 +    0.132s [INF] [WIN     ] Resize 窗口=692,1525 1240x860 客户区=1240x860
2026-11-02 17:09:33.972 +    9.685s [INF] [TIMER   ] bgTimer 触发：窗口移动/缩放后重抓壁纸
2026-11-02 17:09:39.008 +   14.722s [INF] [GLASS   ] 底图没变，跳过重抓 判定耗时=0ms
```

模块：`BOOT` 环境 / `CFG` 配置 / `WIN` 窗口移动缩放 / `TIMER` 定时器 / `GLASS` 玻璃底图 / `WEB` WebView2（含渲染进程崩溃）/ `MSG` 界面消息 / `UI` 界面日志区同步的双写 / `SYS` 生命周期。
级别：`INF` 正常、`WRN` 出了错但能继续、`ERR` 出错并带完整堆栈。

用 PowerShell 读（程序占着文件，必须共享读）：
```powershell
$f = "$env:LOCALAPPDATA\BenziHunter\logs\app-$(Get-Date -f yyyyMMdd).log"
$fs = [IO.File]::Open($f,'Open','Read','ReadWrite'); $sr = New-Object IO.StreamReader($fs,[Text.Encoding]::UTF8)
$sr.ReadToEnd(); $sr.Dispose(); $fs.Dispose()
```

**已知问题 / 限制**
- **nhentai 必须走代理**（`127.0.0.1:7890`），且图片 CDN 在国外，速度受代理限制；已用 4 路并发缓解。
- 禁漫部分镜像站首页能开但搜索接口挂，软件会自动跳过这类域名（`ResolveJm` 里做真实搜索探测）。
- 禁漫多章节作品会逐章下载后合成一个 zip，章节很多时会慢。
- 绅士漫畫的整文件 GET 会被服务端挂死，所以必须分片；分片偶发 194 字节垃圾响应，靠重试兜。
- 不做登录态：需要登录/付费的章节会失败，属预期。
